# PM 自我审核闸门

老板不逐刀点确认。**PM 在审核 PASS 后承担自我审核，并决定是否开启下一项。**

## PM 必须做的自审（PASS 之后）

对照落盘文件，写出 `records/pm/PM-D#.md`（或追加 `SELF-AUDIT` 节），逐条判定：

| 检查项 | 通过条件 |
|--------|----------|
| 报告链齐全 | 有 ARCH + EXEC + REVIEW，且 REVIEW=PASS |
| 定界遵守 | REVIEW 越界检查 PASS；EXEC 声明遵守定界 |
| DoD | 分发单/BACKLOG 的 DoD 在 REVIEW 中均有结论 |
| 风险 | 无未披露红线改动；编译/测试债已写明 |
| 下一项就绪 | BACKLOG 下一项依赖已满足；或本批应结束 |

## 裁决（写入 PM 报告）

```text
## PM 自我审核裁决
- 结论：开下一项 D? / 结束本批 / 升级老板
- 理由：一句话
- 债（不挡）：…
```

| 结论 | 主控动作 |
|------|----------|
| **开下一项** | 主控立即派主程（若需新 ARCH）或执行，**不必等老板** |
| **结束本批** | 更新 BOARD/BACKLOG 为完成；通知老板摘要 |
| **升级老板** | 仅当：FAIL 反复、缺契约、要改产品口径、触碰组织红线、PM 无法判定 |

## 主控

- 收到 PM「开下一项」→ 视为闸门打开，继续流水线  
- 不得跳过 PM 自审直接开下一刀  
- 老板仍可随时口头覆盖（暂停 / 改刀 / 改口径）

## 与「审核岗」分工

- **task-review：** 技术/定界/DoD 验收（PASS/FAIL）  
- **PM 自审：** 流程完整性 + 是否推进 + 进度登记 + 升级决策
