# Official UnrealSharp Source Map

## Purpose

Use this index when a task needs a current official answer or an API detail not covered by the compact reference files. The local references distill every documentation topic listed below; this map preserves complete page-level coverage without embedding a brittle verbatim website mirror.

Source snapshot checked: 2026-08-05. Start with the [official complete LLM-friendly documentation](https://www.unrealsharp.com/llms-full.txt) for a fresh consolidated view, then use the specific page that matches the task. Treat the installed version and generated bindings as authoritative for API spelling.
