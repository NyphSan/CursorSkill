# Unreal Engine Python Glossary

- **unreal module**: The root Python module exposing UE5 reflected classes, structs, enums, and functions.
- **Blutility**: Editor utility Blueprint / Python script that can be run from the Content Browser or toolbar.
- **Editor Utility Widget**: A UI widget built in-editor using Python/Blueprint.
- **Subsystem**: A UE pattern for manager-style access; e.g., `StaticMeshEditorSubsystem`.
- **CDO**: Class Default Object, the default instance of a class used to read defaults.
- **AssetData**: Lightweight reference to an asset in the Content Browser or Asset Registry.
- **Geometry Script**: UE's Python-exposed mesh manipulation framework.
- **Datasmith**: Import pipeline for CAD/DCC data into UE.
- **GLTF/USD**: Open 3D exchange formats supported by UE import/export tools.
